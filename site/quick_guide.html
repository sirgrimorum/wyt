WYT quick guide

The writing loop, its keys and commands, and the Neovim you need to write with it. Full rules: USER_GUIDE.md. Install and API key: README.md.

The loop

  1. Create:WYTNew p. Pick the language with care: switching it later hides the groups written in the old one.
  2. Collect ideasWrite the Description, then :WYTNew i or type - an idea under ## Ideas.
  3. Group:WYTNew g gathers ideas into a ## Group:. Order with S-↑ S-↓.
  4. ImplementS-Tab on a group: a new section with its own plan, or, at the depth limit, placeholders in text.wyt.md.
  5. Write]w jumps to the next placeholder and expands it: generate with the LLM or write it yourself.
  6. Export:WYTExport assembles everything into export.wyt.md at the root.

Saving commits, so you never touch git by hand. Every WYT jump saves first.

WYT keys normal mode, WYT files

S-TabplanOn a group or its ideas: implement it, or enter it if already done. On the # title: back to the parent plan.
S-↑ S-↓planMove the idea or group under the cursor.
]w [wtextJump to the next / previous placeholder and expand it.
\wetextExpand the placeholder under the cursor (<leader>we; leader is \ by default).

WYT commands

:WYTNew pNew project.
:WYTNew iNew idea, free or by the type's guided questions.
:WYTNew gNew group. Select idea lines with V first to pre-tick them.
:WYTNavPick any file or section of the project.
:WYTGoto …plan text config export parent: jump to that file.
:WYTSearchSearch characters, setting, chronology, concepts, sources.
:WYTGenerateGenerate at the cursor: a bridge between paragraphs in text, new ideas in a plan. Add an instruction to steer it.
:WYTExpandSame as \we; next / prev as ]w / [w.
:WYTExportRebuild export.wyt.md.
:WYTConfigclaude or openai: set the provider and its key.
:checkhealth wytCheck the install and where the key comes from.

Pickers and prompts

In :WYTNav and :WYTNew g: type to filter, Tab ticks an item, Enter confirms, Esc cancels. In a prompt, Esc cancels and leaves things as they were.

Neovim for writers

You start in normal mode, where keys are commands. i enters insert mode to type; Esc goes back. : opens the command line.

:w :q :wq :q!Save / quit / save and quit / quit discarding changes.
i a o OInsert before / after the cursor / on a new line below / above.
u C-r .Undo / redo / repeat the last change.
w b eNext word / previous word / end of word.
0 $ gg GStart / end of line; top / bottom of file.
{ }Previous / next paragraph.
gj gkDown / up by screen line, for long wrapped paragraphs.
/text n NSearch forward; next / previous match.
C-o C-iJump back / forward to where you were.
V j kSelect whole lines, for example ideas before :WYTNew g.
dd yy pCut / copy the line; paste below.
ciw cis cipChange the word / sentence / paragraph under the cursor.
gqipReflow the paragraph to the text width.
gt gT C-w wNext / previous tab; next window.

Writing comfort

:set wrap linebreak wraps long paragraphs at word boundaries.

:set spell spelllang=en (or es) marks typos: ]s [s jump between them, z= suggests fixes.

Stuck? Press Esc a few times to get back to normal mode. :help ciw explains any key or command.
